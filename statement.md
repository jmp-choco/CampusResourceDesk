# Campus Resource Desk

## 1. Problem Statement

Managing college resources manually can make it difficult to know which resources are available, borrowed, or returned.

Campus Resource Desk is a simple Python-based system that helps manage college resources in an organized way.

## 2. Objective

The main objectives of this project are:

- To keep records of college resources.
- To check the availability of resources.
- To manage borrowing and returning of resources.
- To update resource quantities.
- To provide simple reports about resources.

## 3. Target Users

The project can be used by:

- College students
- Lab assistants
- Teachers
- Resource desk staff

## 4. Scope of the Project

The system can manage resources such as:

- HDMI cables
- Projectors
- Calculators
- Laptop chargers
- Extension boards
- Cameras
- Other college equipment

The project stores resource information in a JSON file.

## 5. Main Features

### Resource Management

- Add a new resource
- View resources
- Search for a resource
- Update resource quantity

### Borrow and Return

- Borrow a resource
- Return a resource
- Automatically update available quantity

### Reports

- View available resources
- View borrowed resources
- View usage information

## 6. Technologies Used

- Python
- JSON
- VS Code

## 7. Expected Result

The project provides a simple system for managing college resources and helps users easily check the availability and usage of resources.

## 8. Conclusion

Campus Resource Desk is a beginner-level Python project that demonstrates the use of functions, lists, dictionaries, loops, conditions, modules, file handling, and JSON.
