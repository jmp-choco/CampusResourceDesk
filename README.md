# Campus Resource Desk

## Introduction

Campus Resource Desk is a simple Python project made for managing college resources.

It helps to keep track of resources such as HDMI cables, projectors, calculators, chargers and other equipment.

The project allows the user to add resources, view resources, borrow resources, return resources and check reports.

## Features

The main features of the project are:

1. Add a new resource
2. View all resources
3. Search for a resource
4. Update resource quantity
5. Borrow a resource
6. Return a resource
7. View available resources
8. View borrowed resources
9. View usage information

## Technologies Used

- Python
- JSON
- VS Code

## Project Files

- `main.py` - Main menu of the project
- `resources.py` - Handles resource management
- `transactions.py` - Handles borrowing and returning
- `reports.py` - Shows different reports
- `storage.py` - Saves and loads resource data
- `validators.py` - Checks user input
- `test_project.py` - Used for testing
- `data/resources.json` - Stores resource data
- `statement.md` - Contains the project statement
